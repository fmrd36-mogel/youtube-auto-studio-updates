# YouTube Auto Studio v2 — Windows 사용 설명서

## 이번 버전
기존 v1의 3채널 OAuth 인증/채널 ID 검증/비공개 업로드/SQLite 작업 목록을 유지하면서, **쇼츠 제작** 탭을 추가했습니다. 제목과 빈 줄로 구분한 장면별 대본을 입력하면 720×1280 세로 카드 영상, 화면 문구, 무음 오디오가 들어간 MP4를 자동 제작합니다. Windows TTS 내레이션은 선택 기능이며 설치된 한국어 음성 팩에 따라 동작이 다릅니다. 외부 소스 자동 수집, AI 모델 대본 생성, vidIQ·Metricool·Higgsfield API 직접 연동, 완전 무인 게시/예약 공개는 아직 미구현입니다.

## 매우 중요: 기존 탄단지 채널 인증 유지
v1 폴더를 지우거나 덮어쓰지 마세요. v2 ZIP을 **새 폴더**에 압축 해제한 후 프로그램을 종료한 상태에서 아래 파일을 v1에서 v2로 **복사**하세요.
- `secrets/client_secret.json`
- `secrets/token_channel_1.json` (채널 2·3도 연결했다면 해당 토큰도)
- `data/studio.db` (기존 채널 ID와 업로드 작업 이력)
인증 파일은 공유하거나 업로드하지 마세요. 이 ZIP에는 인증 정보나 기존 업로드 이력이 포함되지 않습니다.

## 사전 준비
1. Windows Python 3.11 이상 설치 (설치 시 PATH 추가)
2. FFmpeg 설치 후 `ffmpeg -version` 명령으로 인식되는지 확인. 예: `winget install Gyan.FFmpeg` 실행 후 명령창 재시작. 패키지 식별자는 환경에 따라 달라질 수 있습니다.
3. `start_windows.bat` 더블클릭. 처음 실행 시 인터넷을 통한 Python 패키지 설치가 필요합니다.
4. 웹 관리 화면 → **쇼츠 제작** → 채널 선택, 제목과 장면 대본 입력 → MP4 자동 제작.
5. 제작된 영상 경로를 **업로드 작업** 탭에 입력하고 사용 권한 확인, 등록, 최종 승인 저장, 화면 새로고침, 비공개 업로드 실행.
6. YouTube Studio에서 실제 비공개 영상이 생성됐는지 확인하세요.

## 운영 주의
- 기본 제작 방식은 **AI가 새 대본을 쓰는 기능이 아닌**, 입력한 대본을 영상으로 변환하는 방식입니다.
- TTS는 기본 꺼짐. 켜면 Windows 설치 음성에 의존하며 환경에 따라 실패할 수 있습니다. 처음에는 끄고 테스트하세요.
- 화면에 보이는 글은 문장별 타이밍 자막이 아닌 **장면별 텍스트 카드**입니다.
- 영상/음원/이미지 권리 확인 후 업로드하세요.
- 오류 후 재시도 전 YouTube Studio에서 기존 업로드 여부를 확인하세요.
- v1과 v2를 동시에 실행하지 마세요. 앱은 로컬 개인 PC용이며 인터넷에 공개하지 마세요.
